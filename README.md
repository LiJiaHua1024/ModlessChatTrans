# ModlessChatTrans

## 基于 AI 的 Minecraft 实时聊天翻译器

---

[English](README_EN.md) | 简体中文

## 特点

- **AI 高质量翻译**：利用先进的大语言模型 (LLM) 进行翻译，在口语化聊天场景下显著超越传统翻译引擎
    - **专为 Minecraft 优化的提示词**：经过大量优化的提示词工程优化，确保 LLM 深刻理解 Minecraft 的聊天风格、术语和文化背景，实现精准翻译
    - **自定义术语表**：完美解决游戏黑话或特定服务器术语的翻译难题。用户可自定义术语及其翻译，工具会自动将这些术语加入 LLM
      请求，确保关键信息准确传达
    - **上下文翻译**：支持结合前文聊天消息的语境进行翻译（接收消息与发送消息均已支持），极大提升复杂对话、省略语和指代关系的翻译准确性与连贯性
    - **备用模型与多策略容灾**：支持配置备用模型及四种切换/竞速策略（直接切换、重试耗尽后切换、首次失败竞速、始终竞速），并兼容 OpenRouter 扩展模型路由语法，确保高可用与低延迟
- **简单易用**：通过直接读取 Minecraft 日志文件自动获取聊天消息，彻底摆脱传统 OCR
  方案的不稳定与操作繁琐。提供轻量级网页界面，翻译结果一目了然，消息发送便捷高效，整体体验流畅自然，集成度仅次于原生游戏模组
- **现代化界面**：采用 Fluent Design 风格，界面美观。经过精心组织，功能模块层次分明，导航与操作逻辑符合直觉，带来直观易用且赏心悦目的用户体验。同时提供基于 WebView2 的极简版 (`nano`)，进一步降低资源占用
- **无需模组**：作为当前社区中少有能实现无模组运行的 Minecraft
  翻译解决方案，本工具规避了模组兼容性问题，并免除繁琐的版本适配工作。无论您使用的是原版客户端、限制模组的环境，或是追求最简部署，都能获得优秀的翻译体验
- **Minecraft 格式化代码渲染**：网页界面完整支持 Minecraft 文字格式，呈现与游戏客户端一致的视觉效果
- **多种翻译服务支持**：支持 23 个大语言模型 (LLM) 提供商 和 9 个传统翻译服务提供商。对于传统翻译服务，既可直接使用集成的免费在线翻译，也可使用用户自己的
  API Key
- **智能消息分类与黑名单**：除零延迟的内置规则外，还支持使用 Jev 语义模型或混合模式精准区分玩家聊天与服务器/系统消息（适应各类自定义服务器头衔）；配合用户黑名单与消息内容黑名单（支持关键词与正则表达式），轻松屏蔽广告与刷屏干扰
- **TTS 语音朗读与 Pre-TTS**：集成 Edge TTS 语音合成与本地音频播放，按顺序自动朗读接收到的译文，支持网页端长按插队朗读及在配置文件中设置静音用户；内置 Pre-TTS 热词预合成功能，可提前为高频缓存译文生成音频，大幅降低朗读延迟
- **智能翻译缓存**：所有翻译结果均采用 LFU（最不常用淘汰）策略可靠存储于本地缓存中。工具会优先匹配历史缓存，大幅提升重复消息的响应速度并节省 API 配额，同时支持在设置中一键清理未曾复用的缓存条目
- **多主题与富交互网页界面**：提供 6 种主题（默认、Material、Fluent、拟物、赛博朋克、复古终端）及一键切换的红温模式 (Rage Mode)；网页端支持消息类型过滤、重复与相似消息智能合并折叠、长按气泡切换原文/译文或复制/朗读、Token 与耗时统计标签以及 SSE 断线自动重连恢复
- **多语言界面**：支持十种常用语言，主要采用 GPT-5 进行翻译，确保界面文本精准自然，让全球玩家都能轻松上手

### 下载并启动程序

#### 方式一：直接运行（适用于 Windows 用户）

这是最简单的方式，推荐所有 Windows 用户使用。

1. 前往项目的 [**Releases 页面**](https://github.com/LiJiaHua1024/ModlessChatTrans/releases/latest)，下载最新的 `.exe`
   文件（通常提供以下三个版本，详细对比见下方“版本区别说明”）：
    - `ModlessChatTrans_v*.exe`：标准版（主力版本，功能与兼容性最完整）
    - `ModlessChatTrans_v*-lite.exe`：Lite 精简版（自研轻量引擎，保留完整桌面界面）
    - `ModlessChatTrans_v*-nano.exe`：Nano 极简版（自研轻量引擎 + WebView2 轻量界面，体积极小）
2. 直接运行下载的 `.exe` 文件，程序将启动
3. 程序启动后，按照界面上的提示进行配置（详细配置见下文“程序界面配置”部分）

#### 版本区别说明

自 v3.3.0 起，项目为不同使用场景提供了三个 Windows 发行版本：**标准版**、**Lite 版**与 **Nano 版**。三者均完整支持核心的 AI / 传统翻译、自定义术语表、上下文翻译、备用模型、黑名单、TTS 语音朗读及多主题网页界面，并各自匹配独立的自动更新通道；主要差异集中在底层翻译依赖、桌面设置界面技术及安装包体积：

- **标准版（`ModlessChatTrans_v*.exe`）**：项目的主力版本，推荐绝大多数用户首选
    - **桌面界面**：基于 PySide6 的原生 Fluent Design 桌面界面，包含全部 11 个配置菜单
    - **翻译引擎**：使用成熟的第三方依赖库（`litellm` 与 `translators`），提供最广泛的模型和接口兼容性，包含对 Google Vertex AI 等全部 23 个 LLM 提供商与全套传统翻译服务的完整支持
    - **体积与定位**：体积约 127 MB（以 v3.3.5 为例），兼容性最全、运行最稳健
- **Lite 版（`ModlessChatTrans_v*-lite.exe`）**：在完整保留原生桌面界面与功能的同时大幅缩减体积
    - **桌面界面**：完整保留基于 PySide6 的 Fluent Design 桌面设置界面与全部 11 个配置菜单，界面与交互体验与标准版一致
    - **翻译引擎**：移除较重的第三方库，替换为项目自研的轻量实现：
        - **自研轻量 LLM 网关（替代 `litellm`）**：通过直接 HTTP 请求接入，完整支持 OpenAI、Azure OpenAI、Anthropic Claude、Google Gemini、Google Vertex AI、DeepSeek、OpenRouter、Mistral、Moonshot 等全部声明服务商，支持深度翻译、推理强度控制与 JSON 结构化输出（仅 GitHub Copilot 不再提供无 API Key 的交互式设备授权流程）
        - **自研轻量免费翻译引擎（替代 `translators`）**：直接内置支持 Bing、Google、Yandex、阿里云、彩云、有道、DeepL Free、搜狗、讯飞等免费在线翻译服务；付费传统翻译接口与标准版完全相同
    - **体积与定位**：体积约 41 MB（较标准版大幅瘦身），适合希望明显减小安装包大小、同时保留完整原生界面与功能的用户
- **Nano 版（`ModlessChatTrans_v*-nano.exe`）**：极致精简版本，兼顾极小体积、快速启动与低内存占用
    - **桌面界面**：彻底移除体积庞大的 Qt / PySide6 运行库，改用 Windows 系统内置的 **Microsoft Edge WebView2** 呈现轻量桌面设置界面（Windows 11 开箱即用）；涵盖消息捕获、翻译服务（含备用模型）、翻译结果显示（含 TTS / Pre-TTS）、消息发送、上下文翻译、术语表、黑名单、启动、关于与设置等全部核心页面，仅在图形界面中精简了独立的“消息分类”设置页（仍可在配置文件中配置，默认使用内置规则）
    - **翻译引擎**：同样采用自研轻量 LLM 网关与轻量免费翻译引擎；在此基础上移除了 Google Vertex AI 服务账号认证支持（标准的 Google Gemini API 凭 API Key 正常使用）
    - **体积与定位**：体积约 22 MB，适合追求极致轻量体验、更低资源占用或使用 Windows 11 的用户

#### 方式二：从源代码运行 (适用于 Linux / 高级用户)

此方法适用于所有 Linux 用户，以及希望体验最新功能或自行修改代码的 Windows 高级用户。

**第一步：安装先决条件**

请确保您的系统已安装`uv`。

- **uv 安装**: `uv` 是一个极速的 Python 包管理器。请在终端运行以下命令安装：
    - **Linux / macOS**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
    - **Windows**: `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`

**第二步：获取源代码**

我们提供两种获取源码的方式：

- **稳定版，推荐给普通用户**:
    1. 前往项目的 [**Releases 页面**](https://github.com/LiJiaHua1024/ModlessChatTrans/releases/latest)
    2. 下载名为 `Source code (zip)` 或 `Source code (tar.gz)` 的源码压缩包
    3. 将文件解压到您喜欢的位置

- **开发版，适用于开发者**:  
  如果您希望获取最新的、可能尚不稳定的开发中代码，请使用 `git` 克隆本项目。
  此方式需要您预先安装 [Git](https://git-scm.com/downloads)。
  ```bash
  git clone https://github.com/LiJiaHua1024/ModlessChatTrans.git
  ```

**第三步：创建环境并安装依赖**

1. 打开终端，进入您解压或克隆的项目文件夹
   ```bash
   cd ModlessChatTrans
   ```
2. 使用 `uv` 创建虚拟环境并安装所有依赖
   ```bash
   # 1.创建虚拟环境
   uv venv
   
   # 2.激活环境
   # Windows用户请执行：
   .\.venv\Scripts\activate
   # Linux用户请执行：
   source .venv/bin/activate
   
   # 3.安装项目依赖
   uv sync
   ```

**第四步：运行程序**

环境配置完成后，直接在终端中运行以下命令即可启动程序：

```bash
modless-chat-trans
```

**第五步：配置并使用**

程序启动后，在GUI界面进行配置，包括填写 Minecraft 日志路径、选择翻译语言等细节，按照程序界面上的提示一步步操作即可。
如果您在配置中遇到问题，可以参考本 README 中的“程序界面配置”部分，那里有详细的菜单说明。

### 程序界面配置

程序的界面左侧菜单分为上部 9 个主要菜单和下部 2 个辅助菜单，共计 11
个菜单。下部菜单包括“关于”和“设置”，其中“设置”包含界面语言、缓存管理和更新设置，将在后续说明。首先介绍上部 9 个菜单。

> **新手导航**：如果您觉得以下配置项繁多，希望快速上手，
> 我们为您准备了一份 [**快速上手指南**](./docs/easy_guide_zh.md)，
> 帮助您在三分钟内完成核心配置并开始使用。

*难以理解的配置项，程序中都有说明按钮，点击即可查看详细说明。*

#### 消息捕获

此菜单用于配置如何从日志文件中读取 Minecraft 聊天消息。

- **Minecraft 日志位置**：填写 Minecraft 日志文件夹的路径。若不确定路径，可通过网络搜索获取
- **源语言**：指定接收消息的语言。若不确定，可留空以启用自动识别
- **目标语言**：指定将接收消息翻译成的目标语言
- **日志编码**：选择程序读取 Minecraft 日志的编码格式。默认“auto”通常有效，若出现问题，可尝试切换为“GBK”等其他编码
- **监控模式**：提供“高效模式”和“兼容模式”两种选项。“高效模式”可降低资源占用，一定程度上提升游戏流畅度；
  “兼容模式”适用于较高版本的 Minecraft，以适应其日志优化机制
- **过滤服务器消息**：启用后，将过滤不包含玩家名称的服务器消息/系统消息（如服务器公告）
- **替换乱码字符**：启用后，程序将假设乱码字符为 Minecraft 格式化代码分节符，并进行替换，以还原可读形式

#### 翻译服务

此菜单用于配置翻译服务。

首先，选择翻译服务类型：AI 翻译（推荐）或传统翻译服务。

- **AI 翻译**：
  页面顶部支持在**主力模型**与**备用模型**标签页之间切换，可分别配置主备模型参数：
    - **选择服务**：选择 AI 模型的提供商
    - **API Key**：填写 API 密钥
    - **API 地址**：若需自定义 API 端点（如用于中转或镜像站），请填写端点地址（不包含“/chat/completion”路径）
    - **模型代号**：指定使用的 AI 模型。使用 OpenRouter 时支持扩展后缀语法（如 `:free`、`:nitro`、`:floor`、`:latency` 或指定提供商排序 `model:provider1,provider2`）
    - **最大输出Token数**：限制单次模型响应的最大输出 Token 数量（范围 `1`–`100000`，默认 `4096`）
    - **深度翻译模式**：启用此模式将使用 CoT 提升翻译质量，但会增加 Token 消耗和延迟
    - **备用模型策略**（仅在启用备用模型时生效）：提供四种容灾与加速策略：
        - **直接切换**：主力模型首次请求失败后，立即回退至备用模型
        - **重试耗尽后切换**：主力模型完成全部自动重试仍失败后，再切换至备用模型
        - **首次失败竞速**：主力模型首次失败后，同时向主备模型发起并发请求，取最先成功的结果
        - **始终竞速**：每次请求都同时调用主备模型，取最先成功返回的结果（延迟最低，但会消耗双倍请求）
- **传统翻译**：
    - **选择服务**：选择翻译服务提供商
    - **API Key**：若有密钥可以填写，选择“不使用”将使用网页在线服务
    - 阿里云/有道/Sogou 使用 `标识:密钥` 格式；Iflyrec（讯飞机器翻译）使用 `AppID:APIKey:APISecret` 格式，且付费 API 需要明确源语言
    - Yandex 还需要填写 Folder ID；Azure 区域资源可填写 Azure 区域，全球资源留空即可

页面底部有“独立设置消息发送翻译服务”选项，将在“消息发送”菜单后说明。

#### 翻译结果显示

此菜单用于配置翻译结果的显示与语音朗读方式。

- **TTS 朗读设置**：使用 Edge TTS 自动将接收到的翻译结果朗读出来，支持网页端控制
    - **启用朗读**：开启后，程序会按顺序自动朗读接收到的译文，不重叠播放
    - **朗读语音**：选择具体语音或保持“自动”，根据译文内容自动选择合适的声音
    - **朗读语速**：支持 5 个语速档位调整（`-50%` 至 `+50%`）
    - **朗读玩家名**：开启后，朗读消息时会连同发言玩家名一起读出
    - **测试朗读**：点击立即试听当前语音与语速效果
    - **Pre-TTS 热词预合成**：分析历史翻译缓存中的高频消息并提前合成为本地音频，以降低实际朗读时的等待时间（支持手动启动、停止与清除缓存音频；开启“朗读玩家名”时此功能不可用）
- **网页设置**：
    - **网页端口**：设置网页界面在本机上的端口号。对于大多数用户，无需修改默认值（`56552`）

#### 消息发送

此菜单用于配置发送消息的翻译。

- **监控剪切板**：启用此复选框后，程序将监控剪切板变化，并将变动内容作为待发送消息进行翻译
- **源语言**：指定用户输入消息的语言（即发送方语言）
- **目标语言**：指定将用户消息翻译成的目标语言

注意：与“消息捕获”菜单中的源语言和目标语言不同，此处设置针对用户发送的消息，而前者针对接收的消息。请根据实际需求区分配置。

关于“翻译服务”中的“独立设置消息发送翻译服务”：若启用，可为消息发送独立配置翻译服务，与接收消息的翻译服务分离。
启用后，可通过切换“翻译服务”界面上方的“玩家消息翻译服务”和“消息发送翻译服务”标签分别配置。

#### 上下文翻译

此菜单用于配置上下文翻译功能，让翻译模型参考前文对话语境，提升多轮交流中的准确性与连贯性（接收消息和发送消息各自维护上下文历史）。

- **上下文分割策略**：
    - **不启用**：按单条消息独立翻译，不附带历史上下文
    - **固定长度**：始终保留固定条数的近期消息作为上下文
    - **基于时间跨度**：若相邻两批消息的时间间隔超过设定阈值，则自动清空旧上下文，避免不相关的旧聊天干扰当前语境
- **最大保留历史条数**：设置最多带入多少条历史消息作为上下文（`0` 表示不限制条数）
- **时间跨度阈值(秒)**：仅在“基于时间跨度”策略下生效，用于判断何时开启新一轮对话上下文

#### 术语表

此菜单对 AI 翻译服务的支持更佳，用于自定义术语表。

- 输入原术语和目标术语，点击添加即可。点击已添加的术语可以编辑。
  对于大多数用户，此功能已足够。详细教程见[术语表教程](./docs/glossary_guide_zh.md)

#### 黑名单

此菜单用于过滤不需要翻译的特定玩家或特定内容消息，仅对接收的玩家消息与系统消息生效，不影响自己发送的消息。

- **用户黑名单**：支持多行批量添加玩家名。匹配时会自动剥离颜色格式化代码、`[MVP+]` 等服务器头衔以及频道前缀，对净化后的玩家名进行不区分大小写的精确匹配
- **消息内容黑名单**：支持添加屏蔽词（不区分大小写的子串匹配）或正则表达式（`/pattern/` 风格或直接开启正则开关），命中规则的消息将被跳过翻译与显示

#### 消息分类

此菜单用于配置如何识别与区分“玩家聊天消息”和“服务器/系统消息”，在拥有自定义头衔或特殊格式消息的服务器中尤为有用。

- **分类方式**：
    - **内置规则**：纯本地规则匹配，零延迟、零额外费用
    - **Jev 模型判定**：调用语义分类模型识别消息类型，分类结果会进行本地缓存；若接口超时或失败将自动回退至内置规则，连续失败时触发熔断暂停以保护体验
    - **混合模式**：先由内置规则进行宽松预筛，仅将疑似或难以判定的消息交由 Jev 模型确认，在保持高准确率的同时减少 API 请求
- **Jev 服务配置**（使用 `Jev 模型判定` 或 `混合模式` 时展开配置）：
    - **接口格式**：支持 `Jev 标准格式`（TypeSafe 官方、OpenRouter 等 OpenAI 兼容端点）及 `Cloudflare AI`
    - **API Key**、**模型**、**端点**：配置分类服务所需的鉴权与请求参数
    - **账号 ID**：仅在选择 Cloudflare AI 时需要填写
    - **请求超时**：设置单次分类请求的超时时间（毫秒），超时后自动回退至内置规则

#### 启动

此菜单用于保存配置并启动程序，同时在启动后显示网页界面访问链接。

- **启动**：
    - **直接启动**：基于当前配置启动程序，不保存至配置文件
    - **保存配置并启动**：先保存配置，然后启动程序
- **保存配置**：将当前配置保存至配置文件

#### 关于

此菜单显示程序信息，包括版本、作者、邮箱、相关链接和许可证。

#### 设置

此菜单用于程序整体设置。

- **语言设置**：选择程序界面的显示语言（非消息翻译语言）。更改后需重启程序生效
- **缓存管理**：
    - **清理不常用缓存**：一键清理翻译缓存中从未被再次命中过的低频条目，保留高频复用缓存
- **更新设置**：
    - **自动检查**：设置自动检查更新的频率
    - **预发布版本**：选择是否包含预发布版本
    - **手动检查**：立即检查更新（下载与当前版本匹配的标准版、`lite` 或 `nano` 更新包）
    - **当前版本**：显示当前程序版本号与版本类型

### 启动后的使用方法

通过“启动”菜单的任意方式启动程序后，“启动”页面将显示“Web 访问链接”卡片。同时，该链接将在启动 1 秒后自动打开网页界面。

- **查看翻译结果**：打开提供的网页链接（推荐使用手机/平板访问或使用电脑副屏显示）。
  若不懂网络配置，可从链接列表自上而下逐一尝试，直至成功访问。网页上将显示翻译后的聊天消息：
    - **顶部筛选**：可按消息类型筛选显示内容（玩家消息、系统消息、错误、提示信息）
    - **智能合并与折叠**：连续重复的消息会自动合并显示计数角标（`xN`），连续相似的系统或玩家消息会自动折叠收纳（`+N`），点击即可展开查看详情
    - **长按交互菜单**：在任意消息气泡上长按，可快速切换查看原文/译文、复制文本，或立即中断当前队列进行 TTS 语音朗读
    - **右下角悬浮菜单 (FAB)**：点击展开快捷操作，可切换深色模式、清空消息列表、开启/关闭**红温模式 (Rage Mode)**，以及在 6 种网页主题间实时切换
- **发送消息**：
    - **网页输入方式（推荐）**：在网页的消息输入框中输入内容，点击发送按钮。
      翻译完成后，网页将显示 Info 级提示，表示结果已复制到剪切板。
      随后，在 Minecraft 聊天界面（默认按 T 键打开）中，按 Ctrl+V 粘贴翻译结果。此方式避免了“卡输入法”的问题。
      若在右下角悬浮菜单开启了**红温模式 (Rage Mode)**，网页将切换至红温主题，发送的文本也会以极具攻击性的 Minecraft 玩家口吻进行翻译输出（使用传统翻译服务时会自动退回普通翻译）
    - **剪切板监控方式**：前提需在“消息发送”中启用“监控剪切板”。
      输入消息后，按 Ctrl+A 全选并 Ctrl+C（或 Ctrl+X）复制/剪切到剪切板，程序将捕获并翻译。
      同样的，网页显示 Info 级提示后，使用相同操作在 Minecraft 中粘贴

### 注意事项

若使用低版本 Minecraft（如 1.8.9，常用于 PVP），建议先启动 Minecraft 并等待游戏窗口出现后，再点击程序中的启动按钮。
否则，可能导致 Minecraft 日志不生成，无法翻译接收的消息。
